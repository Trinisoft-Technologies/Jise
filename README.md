Jise Logistics is a modern, reliable, mobile-first logistics and last-mile delivery platform.

Jise connects customers who need to send packages with verified delivery riders. It provides delivery booking, rider onboarding and KYC verification, dispatch management, package tracking, QR/OTP delivery confirmation, payment simulation, and operational analytics.

This is a functional proof of concept that will be demonstrated to stakeholders and prospective customers. It must look and behave like a real product, not a static UI mockup.
